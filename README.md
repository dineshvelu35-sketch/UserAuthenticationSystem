# User Authentication System

A beginner-friendly C++ console application that demonstrates a simple user authentication system using file handling.

## Features

- User Registration
- User Login
- Input Validation
- File Handling (fstream)
- Object-Oriented Programming (OOP)

## Technologies Used

- C++
- File Handling
- OOP

## Future Improvements

- Password Encryption
- Forgot Password
- Email Validation
- Admin Panel
