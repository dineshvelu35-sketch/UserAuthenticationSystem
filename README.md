# User Authentication System

A beginner-friendly C++ console application that demonstrates a simple user authentication system using file handling and object-oriented programming.

## Features

- User Registration
- User Login
- File Handling using `fstream`
- Input Validation

## Technologies Used

- C++
- OOP
- File Handling (`fstream`)

## Future Enhancements

- Console-based User Interface
- Graphical User Interface (GUI)
- Password Encryption
- Forgot Password
- Email Verification
- Admin Dashboard
- Database Integration (MySQL)
- Profile Update
- Password Reset
- Better Input Validation

## How to Run

1. Compile the source code.
2. Run the executable.
3. Register a new account or log in with an existing account.
